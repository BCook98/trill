# Safe creation demos

Use a dedicated demo account or the explicitly isolated Herdr lab with disposable project files and a separate companion identity. Never copy personal credentials, server discovery files, session state or pairing storage.

The Herdr-only creation menu opens terminal tabs, spaces in existing directories and native Git worktrees. A coding agent must be started inside the terminal explicitly. Real agent capture requires authorized sign-in and a disposable repository; scripted demo workloads must stay labeled as synthetic.

Prepare neutral shell output and demo-only history. Exclude credentials, invitations/QRs, notifications, personal repository URLs and private images. Capture actual app states without retouching terminal content. Inspect an unconfirmed create result before retrying; do not make another mutation merely to obtain a clean recording.

Use `scripts/demo-lab.py` for real Herdr/HTTPS capture and the [scripted runtime](DEMO_RUNTIME.md) for safe API/UI fixtures without Herdr or an agent.
