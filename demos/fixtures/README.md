# Real demo workspace

Field Notes is a small local website for native Trill capture. The lab copies it into an isolated project, opens a real tmux shell, and serves it on loopback through the real companion proxy. It contains no fabricated coding-agent transcript or status.

The adaptive theme and accessible bookmark controls were produced by the real Codex demo session on 24 October 2026 and reviewed before inclusion. `scripts/demo-lab.py codex` explicitly starts a new real Codex task in an owned idle lab shell; it is never an automatic side effect of starting the lab. It uses the installed signed-in Codex CLI and can incur normal model usage. Stop preserves this terminal/agent session.
